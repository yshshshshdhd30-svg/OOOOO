# النص ☜ صوت | Text ☞ Voice — نسخة 4 ملفات

هذه نسخة Static بسيطة لا تحتاج إلى Build Process أو TypeScript أو Wrangler.

## الملفات
- `index.html` — الصفحة الرئيسية.
- `script.js` — وظائف الموقع وتحويل النص إلى صوت من خلال SpeechSynthesis في المتصفح.
- `stylo.css` — التصميم والتنسيق.
- `README.md` — تعليمات الاستخدام.

## النشر
ارفع الملفات الأربعة إلى الاستضافة كما هي، واجعل `index.html` هو الصفحة الرئيسية.

> ملاحظة: هذه النسخة تستخدم أصوات المتصفح. خدمات Firebase/Gemini والخادم الموجودين في المشروع الأصلي لم يتم تضمينهما حتى تبقى النسخة قابلة للرفع كملفات ثابتة بدون Build.
